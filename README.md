# Sad Caption Android

Android Studio-compatible project for the Sad Caption app.

## Build APK
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Select **Build > Build App Bundle(s) / APK(s) > Build APK(s)**.
4. The debug APK will be in `app/build/outputs/apk/debug/`.

Minimum Android: 6.0 (API 23).
No internet permission is required.
